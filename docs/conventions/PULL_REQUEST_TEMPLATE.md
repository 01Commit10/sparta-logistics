# PR 템플릿

PR을 올릴 때는 본문만 덜렁 올리지 않고, 팀이 파악하기 쉽도록 아래 항목을 채워 작성합니다.

- **제목(Title)**: 커밋 메시지와 유사하게 직관적으로 작성
    - *예시*: `[Feat] 사용자 소셜 로그인 기능 구현 (#12)`
- **PR 본문 구성**:
    - **[작업 목적]**: 어떤 이유로 이 작업을 했는지 요약
    - **[주요 변경 사항]**: 핵심적으로 수정한 로직이나 추가된 파일 설명
    - **[관련 이슈]**: 연동된 이슈 번호 링크 (`Closes #12` 또는 `#12`)
    - **[테스트 결과]**: 스크린샷, Postman 테스트 결과, 또는 유닛 테스트 통과 여부 기재
    - **[리뷰어 요청 사항]**: "이 부분 로직이 최선인지 봐주세요" 등 피드백이 필요한 지점 명시

## 복사용 본문

```markdown
## 작업 목적


## 주요 변경 사항
-

## 관련 이슈
Closes #

## 테스트 결과


## 리뷰어 요청 사항

```
