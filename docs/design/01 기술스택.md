# 1. 기술스택

Backend: Java 21, Spring Boot 3.5.16, Spring Data JPA, Validation, Spring Security Crypto(BCrypt)  
MSA: Spring Cloud 2025.0.3 (Gateway, Eureka, OpenFeign, LoadBalancer)  
Resilience: Resilience4j Circuit Breaker·Retry 도입 후 제거, 타임아웃·오류 분류로 대체  
Database: PostgreSQL 18 (서비스별 스키마 5개)  
Cache: Redis 7.4, Caffeine  
Auth: JWT(jjwt 0.12.6), Redis 토큰 상태 관리  
Build: Gradle 멀티 모듈  
Container: Docker, Docker Compose  
Monitoring: Spring Boot Actuator, Prometheus  
Collaboration: Git, GitHub  
Testing: JUnit 5, Mockito, H2, Testcontainers, WireMock, ArchUnit, k6, Postman  
Notification: Slack Incoming Webhook
