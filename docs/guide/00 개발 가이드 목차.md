# 00. 개발 가이드 목차

> 작성자: 대진 · 기준: `dev` d6af869 · 최종 수정: 2026-10-16
> Gateway·인증, 서비스 간 장애 대응, User·Auth API, Slack 알림을 **내 서비스에서 어떻게 쓰는지** 정리한 문서입니다.
> 모든 가이드는 **코드 기준**입니다. 설계 문서(`design/`, `Common/SYS-*`)와 다르면 가이드가 맞습니다.

## 빠르게 쓰기: 사용법 (먼저 보세요)

원리는 빼고 **복붙 예제 → 응답별 대처 → 하지 말 것**만 담은 1~2쪽 문서입니다. 대부분은 이것만 보면 됩니다.

| 내가 하려는 것 | 사용법 |
|---|---|
| Controller에서 로그인 사용자 받기, 내 API 경로 확인, 401·403·503 대처 | [[Gateway 사용법]] |
| 다른 서비스 호출(Feign), 실패 예외 3종 처리 | [[Feign 호출 사용법]] |
| 다른 서비스에서 사용자 정보 조회 (따라 만드는 예제) | [[예시 - 다른 서비스에서 사용자 조회]] |
| 주문에서 상품·업체 조회, 배송에서 허브 경로 조회 (따라 만드는 예제, 서비스 간 호출 전체 지도) | [[예시 - 주문·배송에서 다른 도메인 조회]] |
| 가입·로그인·토큰 재발급, 다른 서비스에서 사용자 조회 | [[User·Auth API 사용법]] |
| Slack 알림 보내기 (주문 완료 등) | [[Slack 알림 사용법]] |

## 원리까지: 개발 가이드

설계 이유, 요청 흐름 그림, 전체 오류 코드표가 필요할 때 봅니다.

| 내가 하려는 것 | 읽을 문서 |
|---|---|
| Controller에서 로그인 사용자 받기, 권한 검사 위치, 로컬에서 토큰 받기 | [[01 Gateway·인증 가이드]] |
| 다른 서비스 호출(Feign), 타임아웃·Circuit Breaker, Saga 보상 | [[02 장애 대응(Feign) 가이드]] |
| 로그인·회원 API 호출, 다른 서비스에서 사용자 조회(내부 API) | [[03 User·Auth API 가이드]] |
| 주문 완료 Slack 알림 붙이기 (order-ms), 내 서비스에서 Slack 알림 보내기 | [[04 Slack 알림 가이드]] (빠른 시작 0.1절) |
| 통합 테스트 작성(H2·PostgreSQL·WireMock), 전체 서비스 E2E·장애 시나리오 | [[05 통합 테스트 가이드]] |

## 팀 결정이 필요한 것

| 항목 | 관련 | 영향 |
|---|---|---|
| 주문 생성 응답 202(비동기) vs 201(동기) | 다울 | Gateway 주문 타임아웃(15초), Saga 헤더 전달, 알림 의미 |
| 내부 API 호출자 인증(정책 #16) | 전원 | `/internal/**` 보호 방식 |
| 배송담당자 해제 시 진행 중 배송 처리(정책 #15) | 영은·대진 | U16 |
| 허브·업체 내부 존재 확인 API | 이찬·권우 | U20 소속 연결 |
| 재고 차감·배송 생성 멱등성(P1~P4) | 이찬·영은 | Saga 재시도·보상 |
